# Quick Guide: Using "default" Topic

## 🎯 What Does "default" Do?

**"default"** = Generate questions from **ALL SECTIONS** of your document (not just one topic)

---

## 🚀 Quick Start

### Step 1: Run Demo
```bash
cd backend/testing
python demo.py
```

### Step 2: Start a Session
```
Main Menu → 2 (Adaptive Mode) → 1 (Start new session)
```

### Step 3: Enter "default" as Topic
```
Enter topic for quiz generation (or 'default' for whole document): default
```

### Step 4: Get Quiz!
```
✓ Retrieved 5 random documents from entire source
✓ Generated 5 questions

Questions will cover different parts of your material!
```

---

## 📊 Comparison

### Normal Mode (Specific Topic)
```
You: "Neural Networks"
System: *searches for sections about Neural Networks*
Quiz: 5 questions all about Neural Networks
```

### Default Mode
```
You: "default"
System: *picks random sections from entire document*
Quiz: 5 questions from different topics
```

---

## 💡 When to Use "default"

✅ **Use "default" for:**
- General review
- Testing overall knowledge
- Comprehensive practice
- When you want variety

✅ **Use specific topic for:**
- Focused study
- Weak areas
- Exam preparation on specific subjects
- Deep dive into one concept
